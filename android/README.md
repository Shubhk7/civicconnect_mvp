# CivicConnect Android (WebView)

Java WebView wrapper around the existing CivicConnect **website**.
Open **this directory** in Android Studio.

Full setup, URL configuration, emulator networking, and geolocation
limits: repository root [`README.md`](../README.md) and
[`docs/ANDROID.md`](../docs/ANDROID.md).

```bash
./gradlew assembleDebug
```

Default site: `https://kashnet.online`.
